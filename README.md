# Kwork Radar

Python-скрипт для поиска заказов на Kwork. Он проверяет раздел «Разработка и IT», отсеивает заказы по возрасту, бюджету и числу откликов, затем просит локальную модель Qwen оценить соответствие задач профилю исполнителя. Заказы с достаточной оценкой отправляются в Telegram.

## Запуск

1. Установите Python 3 и зависимости: `pip install -r requirements.txt`.
2. Запустите локальный сервер совместимого с OpenAI API приложения (например, LM Studio) по адресу `http://localhost:1234` и загрузите модель `qwen/qwen3.5-9b`. Адрес и название модели можно изменить в `radar.py`.
3. Скопируйте `.env.example` в `.env`, укажите токен Telegram-бота и ID чата. Не публикуйте этот файл.
4. При необходимости измените профиль исполнителя, пороги фильтрации и интервал проверки в `radar.py`.
5. Запустите `python radar.py once` для однократной проверки или `python radar.py loop` для постоянной работы.

Результаты и список уже просмотренных заказов сохраняются локально и исключены из Git. Скрипт зависит от структуры страницы Kwork: при её изменении может потребоваться обновление парсера.
